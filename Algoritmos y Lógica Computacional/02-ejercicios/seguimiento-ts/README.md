## 📖 Descripción

Repositorio de entrega del taller de seguimiento en **TypeScript** para el segundo corte de la asignatura *Algoritmos y Lógica Computacional*.

Cada ejercicio modela un sistema real usando clases, interfaces, tipos, enums y principios de programación orientada a objetos en TypeScript puro, ejecutado con **Bun**.

---

## 🧩 Ejercicios

| Archivo | Sistema modelado | Conceptos clave |
|---|---|---|
| `src/ejercicio1.ts` | Cajero Automático | Clases, sesión, historial, validaciones |
| `src/ejercicio2.ts` | Sistema de Reserva de Hotel | Arrays, enums, filtros, resumen de ingresos |
| `src/ejercicio3.ts` | Carrito de Compras | Catálogo, stock, descuentos, totales |
| `src/ejercicio4.ts` | Digiturno | Cola de espera, turnos preferenciales, historial |

## 🛠 Tecnologías

- [TypeScript](https://www.typescriptlang.org/) — Tipado estático sobre JavaScript
- [Bun](https://bun.sh/) — Runtime y ejecutor de TS sin transpilación previa
- [Node.js](https://nodejs.org/) — Entorno de referencia

---

## ✅ Requisitos previos

- [Bun](https://bun.sh/) `v1.0` o superior

```bash
bun --version
```

> También funciona con `ts-node` si no tenés Bun instalado.

## 🚀 Instalación y uso

**1. Clonar el repositorio:**

```bash
git clone https://github.com/dbarrientos-dev/SeguimientoTS.git
cd SeguimientoTS
```

**2. Instalar dependencias:**

```bash
bun install
```

**3. Ejecutar un ejercicio:**

```bash
bun run src/ejercicio1.ts
bun run src/ejercicio2.ts
bun run src/ejercicio3.ts
bun run src/ejercicio4.ts
```
