# Algoritmos y Lógica Computacional

Repositorio académico y archivo de prácticas, laboratorios, guías teóricas, minijuegos y proyectos desarrollados para la asignatura de **Algoritmos y Lógica Computacional** en la **Universidad CUE Alexander von Humboldt**.

---

## Estructura de Directorios

La organización del repositorio sigue una estructura limpia y escalable por categorías académicas:

```text
Algoritmos y Lógica Computacional/
├── README.md                      # Documentación del módulo
├── 01-teoria-y-guias/             # Material teórico, presentaciones, manuales y normativas
├── 02-ejercicios/                 # Talleres y ejercicios prácticos de programación
├── 03-proyectos-y-juegos/         # Minijuegos interactivos, aplicaciones y portafolios web
├── 04-parciales/                  # Evaluaciones, entregas y seguimientos de exámenes
└── 05-experimental/               # Prototipos, pruebas de concepto e investigación
```

---

## Tecnologías y Lenguajes Presentes

- **JavaScript (ES6+)**: Algoritmos base, estructuras de control, manipulación de arreglos y DOM.
- **TypeScript**: Tipado estático, programación orientada a objetos (POO), interfaces, genéricos y manejo de excepciones.
- **Java**: Estructuras de clases, interfaces funcionales, herencia y calculadoras gráficas con Swing.
- **Python**: Automatización y gestores de tareas experimentales.
- **C**: Programación de sistemas y simulaciones (ej. Conway's Game of Life).
- **HTML5 / CSS3**: Interfaces gráficas y maquetación web para minijuegos y portafolios.
