## 5.1 Catálogo de Prácticas de Programación

La sección `02-ejercicios/` contiene la columna vertebral de los laboratorios prácticos del curso, estructurados en dos grandes bloques: la transición inicial de JavaScript a TypeScript y los talleres avanzados de POO.

| Módulo de Ejercicios | Lenguaje | Descripción y Problemas Resueltos |
| :--- | :--- | :--- |
| **5 Ejercicios de JS a TS** | TypeScript / JS | Casos de negocio reales: lavandería express, gestión de hamburguesas, alcaldía (subsidios), parqueadero y biblioteca. |
| **Ejercicios JS Base** | JavaScript | Primeros algoritmos procedurales y estructurados (`alcaldia.js`, `biblioteca.js`, `hamburguesas.js`, `lavanderia.js`, `parqueadero.js`). |
| **Retos Java** | Java | Estructuras de control y sintaxis inicial en Java. |
| **TypeScript POO & Métodos de Arreglos** | TypeScript | Ejercicios avanzados sobre herencia, clases abstractas, interfaces, genéricos, manejo de excepciones y métodos funcionales (`map`, `filter`, `reduce`). |

---

## 5.2 Análisis de Casos de Negocio

Los ejercicios prácticos simulan escenarios cotidianos para aplicar lógica computacional:
- **Lavandería Express:** Cálculo de tarifas por kilogramo, tipos de lavado y recargos por servicio urgente.
- **Parqueadero (Parquifácil):** Control de entradas, cálculo de tiempo de estancia y cobro por fracción vehicular (motos, carros).
- **Alcaldía (Subsidios):** Evaluación de condiciones socioeconómicas mediante estructuras condicionales compuestas.
