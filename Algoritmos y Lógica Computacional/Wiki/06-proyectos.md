## 6.1 Aplicaciones Interactivas y Minijuegos

La sección `03-proyectos-y-juegos/` agrupa desarrollos web interactivos y proyectos multimedia creados como prácticas de integración de tecnologías (HTML5, CSS3, JavaScript, Phaser):

| Nombre del Proyecto | Tecnologías | Descripción Funcional |
| :--- | :--- | :--- |
| **Juego Blackjack** | JavaScript / HTML5 | Simulación del juego de cartas con lógica de puntuación y control de estados mediante bucles y condicionales. |
| **Piedra, Papel o Tijera** | JavaScript / HTML5 | Aplicación web interactiva básica con lógica de decisiones aleatorias. |
| **Quiz Preguntón** | JS / CSS / HTML | Trivia educativa interactiva con gestión de preguntas y respuestas. |
| **Memoria Desierto** | HTML / JS | Juego de memoria visual basado en correspondencia de cartas. |
| **Pangolin's Bouncing Ball** | HTML5 Canvas / JS | Videojuego arcade clásico de rebote de pelota con sprites y físicas bidimensionales. |
| **The KernelGames / KernelGarden** | HTML / JS / Phaser | Sello indie de videojuegos y portal unificado de proyectos desarrollado por el equipo de ingeniería. |
| **Portafolios Personales** | HTML / CSS / JS | Páginas web de presentación profesional y universitaria de los desarrolladores. |

---

## 6.2 Propósito Académico

Estos proyectos permitieron aplicar los conceptos algorítmicos teóricos en interfaces gráficas reales, manejando eventos del DOM, renderizado en canvas y estructuración de código modular.
