## 3.2 Fichas Técnicas por Tecnología

### JavaScript (ES6+)
- **Uso:** Primer acercamiento a la sintaxis de programación web. Resolución de problemas algorítmicos básicos y estructuras de datos dinámicas.
- **Conceptos:** Funciones flecha, destructuración, callbacks, métodos funcionales sobre arreglos.

### TypeScript
- **Uso:** Estándar principal para el desarrollo de talleres de ingeniería de software y preparación de parciales.
- **Conceptos:** Tipos primitivos, interfaces, clases abstractas, herencia, genéricos (`<T>`), manejo de excepciones y tipos utilitarios (`Partial<T>`).

### Java
- **Uso:** Fundamentación robusta en POO, encapsulamiento, constructores, métodos de acceso y componentes gráficos Swing (`JFrame`, `JButton`, `JPanel`).
