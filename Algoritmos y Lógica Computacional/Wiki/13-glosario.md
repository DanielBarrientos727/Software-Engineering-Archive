## 13.1 Definiciones y Conceptos Fundamentales

- **Algoritmo:** Conjunto ordenado y finito de operaciones que permite hallar la solución a un problema.
- **Clase:** Plantilla o molde que define los atributos y métodos que caracterizan a un objeto en la POO.
- **Encapsulamiento:** Principio de ocultamiento de datos y estado interno de un objeto mediante modificadores de acceso (`private`, `public`, `protected`).
- **Genéricos (`Generics`):** Característica de TypeScript y Java que permite definir componentes reutilizables que funcionan con diversos tipos de datos manteniendo la seguridad de tipado.
- **Herencia:** Mecanismo por el cual una clase (subclase) adquiere los miembros de otra clase (superclase).
- **Interfaz (`Interface`):** Contrato de código que define la firma de métodos y propiedades que una clase debe implementar obligatoriamente.
- **JavaScript:** Lenguaje de programación interpretado, de tipado dinámico, utilizado para la web.
- **TypeScript:** Superconjunto de JavaScript con tipado estático opcional desarrollado por Microsoft.
