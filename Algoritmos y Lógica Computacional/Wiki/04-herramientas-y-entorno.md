## 4.1 Entornos de Ejecución y Compiladores

Para la ejecución y compilación de los programas desarrollados durante el semestre se emplearon las siguientes herramientas documentadas en los manuales del repositorio:

| Herramienta | Versión / Tipo | Uso Principal |
| :--- | :--- | :--- |
| **Node.js** | Entorno JavaScript V8 | Ejecución de scripts y servidores ligeros en JavaScript/TypeScript. |
| **Bun** | Runtime moderno TS/JS | Inicialización ultrarrápida, ejecución de TypeScript sin transpilar y gestión de paquetes. |
| **IntelliJ IDEA** | IDE Java / Multiplataforma | Desarrollo de proyectos orientados a objetos en Java (`.java`, `.class`). |
| **Git / GitHub** | Control de versiones | Ciclo profesional de desarrollo, control de cambios y colaboración en equipo. |
| **GCC / Cargo** | Compiladores C / Rust | Ejecución de simulaciones en C (`life.c`) y experimentación en Rust (`Cargo.toml`). |
